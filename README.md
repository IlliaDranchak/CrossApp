# CrossApp
Проєкт з крос-платформного програмування.

## Предметна область
**Склад**
* **Сутності:** Product (товар), StockBatch (партія), Warehouse (склад), Movement (переміщення).
* **Призначення:** облік залишків товарів по партіях.

## Середовище
* .NET SDK 10.0
* Windows 10 x64
* VS Code (C# Dev Kit)
* Git

## Запуск
```bash
# Збірка проєкту
dotnet build

# Запуск у режимі таблиці
dotnet run --project src/Cli

# Запуск з виводом у форматі JSON
dotnet run --project src/Cli -- --json

## Додаткове завдання: Порівняння розмірів Self-Contained публікацій

* **win-x64:** 153 МБ (160 770 904 байтів)
* **linux-x64:** 157 МБ (165 241 922 байтів)
